# Start this project

To run the implemented local studio: `./start-studio.command` (or `make dev`). Open http://127.0.0.1:3000 and use the local access key printed by that launcher.

`./start-codex.command` starts a separate Codex CLI engineering session with `CODEX_MASTER_KICKOFF.md`. The work in this checkout was carried out directly from that handoff; another agent session is optional.

Read `README.md`, `docs/IMPLEMENTATION_STATUS.md` and `ops/PHASE0_LOCAL_RUNBOOK.md` for what works and the exact limits. This checkout uses the owner-selected V2Manhwa repository; it is independent of the older application. No cloud deployments, real provider calls or publishing are enabled. The full blueprint is not implemented and Phase 0 is not complete.
